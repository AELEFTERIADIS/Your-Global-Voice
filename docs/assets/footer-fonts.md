# Footer fonts

The footer uses genuine regular, upright Cinzel and EB Garamond, self-hosted as webfonts. EB Garamond is an open-source Garamond revival. Both are licensed under SIL OFL 1.1; complete licenses ship in public/footer-font-licenses.txt.

- Cinzel: https://github.com/NDISCOVER/Cinzel — commit dd598495b0fb2ad84270d5cc75d642d2f1e8eabf
  Source fonts/ttf/Cinzel-Regular.ttf, losslessly packaged as WOFF using FontTools.
- EB Garamond: https://github.com/octaviopardo/EBGaramond12 — commit 106a4a6d377987459ae5e68673a4570f13b957fb
  Source fonts/webfonts/EBGaramond-Regular.woff2, copied without modification.

No glyphs were altered. Original font names and copyright metadata remain embedded. No third-party font services are called by the website.
